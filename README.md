# RadarSaham

RadarSaham adalah aplikasi analisis dan dashboard saham berbasis FastAPI, PostgreSQL, dan Streamlit.

## Fitur

- CRUD data saham
- Dashboard Streamlit
- Ranking saham
- Top Broker Score
- Smart Ranking
- Grafik Broker Score
- Grafik Foreign Flow
- Pie Chart Signal
- Alert Trading
- Export Excel
- Update harga otomatis dari Yahoo Finance

## Teknologi

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- Streamlit
- Pandas
- Plotly
- yfinance
